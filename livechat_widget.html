Live Chat Widget

Drop-in plugin — one script tag. Web + mobile ready.

⚙️ Step 1 — Deploy your FastAPI backend Required first

The widget saves chat logs to your main.py FastAPI server and also serves widget.js. Deploy it to any free hosting service — Render is the easiest.

🟣 Render.com — free tier
🚂 Railway.app — free tier
🪰 Fly.io — free tier
A
Add a requirements.txt
fastapi
uvicorn[standard]
openpyxl
B
Push to GitHub, then connect to Render
On Render → New Web Service → connect your repo.
Build command: pip install -r requirements.txt
Start command: uvicorn main:app --host 0.0.0.0 --port $PORT
C
Note your server URL
Render gives you something like https://livechat-chat.onrender.com

🌐 Step 2 — Add to merlkon-khmer.netlify.app Netlify

Two options — pick whichever matches your setup:

A
If you have the source code (React / Next.js / HTML)
Paste this snippet just before </body> in your main HTML file (index.html, _document.js, or app/layout.tsx): 
<!-- Live Chat Widget -->
<script>
  window.LiveChat = {
    apiBase:      'https://livechat-5u7e.onrender.com',  // ← paste your Render URL
    botName:      'Bally',
    brandName:    'Merlkon Khmer Support',
    primaryColor: '#1e8a44',
    whatsapp:     'https://wa.me/46737765168',
    telegram:     'https://t.me/@luxlinna',
    messenger:    'https://m.me/luxlinnaY',
  };
</script>
<script src="https://livechat-5u7e.onrender.com/widget.js" async></script>
B
Or use Netlify snippet injection (no code change needed)
Add a netlify.toml file to your repo root: 
[[headers]]
  for = "/*"
  [headers.values]
    Content-Security-Policy = "default-src 'self' https://livechat-5u7e.onrender.com; script-src 'self' 'unsafe-inline' https://livechat-5u7e.onrender.com"

# Netlify snippet injection — adds the widget to every page automatically
[[plugins]]
  package = "@netlify/plugin-inline-functions-env"
Or go to: Netlify dashboard → Your site → Site configuration → Build & deploy → Post processing → Snippet injection
Paste the script tags above into the "Before </body>" field. No code deploy needed.

export default function ChatScreen() {
  const handleMsg = ({ nativeEvent }) => {
    const data = JSON.parse(nativeEvent.data);
    if (data.type === 'open_url') Linking.openURL(data.url);
  };
  return (
    <WebView
      source={{ html: CHAT_HTML }}
      onMessage={handleMsg}
      javaScriptEnabled
      domStorageEnabled
      style={{ flex: 1 }}
    />
  );
}

Flutter
// pubspec.yaml → webview_flutter: ^4.0.0
import 'package:webview_flutter/webview_flutter.dart';

class ChatScreen extends StatelessWidget {
  final _html = '''
<!DOCTYPE html><html>
<head><meta name="viewport" content="width=device-width,initial-scale=1"></head>
<body style="margin:0">
  <script>
    window.LiveChat = {
      apiBase:   'https://livechat-5u7e.onrender.com',
      mode:      'inline',
      brandName: 'Merlkon Khmer Support',
    };
  </script>
  <script src="https://livechat-5u7e.onrender.com/widget.js"></script>
</body></html>''';

  @override
  Widget build(BuildContext context) {
    final ctrl = WebViewController()
      ..setJavaScriptMode(JavaScriptMode.unrestricted)
      ..loadHtmlString(_html);
    return Scaffold(body: WebViewWidget(controller: ctrl));
  }
}
